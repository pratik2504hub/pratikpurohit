AWS migration and reliability improvement

Availability from 82% to 99%

Pratik planned and executed a move from a hosting provider to AWS for fintech applications, and infrastructure availability rose from 82% to 99%.

Problem

Fintech applications needed to leave a hosting provider for AWS, with better infrastructure availability and a stronger security posture.

My role

Planned and executed the migration as Manager, leading technical delivery across backend engineering, AWS, security, database performance and production reliability.

Approach

Infrastructure setup, validation, cutover, hardening, monitoring and post-migration stabilisation, alongside MySQL optimisation for high-volume workloads.

Challenges

Keeping production reliable through cutover while security hardening, VAPT remediation and RBI and ISO-aligned audit readiness ran in the same period.

Architecture and technology
AWS, EC2, RDS, IAM, monitoring, MySQL
Outcome
Infrastructure availability rose from 82% to 99%.
